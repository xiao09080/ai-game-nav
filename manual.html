① 搞懂钱怎么流动

动手前先花 10 分钟建立「钱的地图」。所有变现动作都在回答同一个公式，后面的章节全是围绕它展开的操作手册。

月收入 = DAU × 人均每日看广告次数 × eCPM ÷ 1000 × 30天

DAU · 日活跃

每天有多少真实玩家打开你的游戏。靠选题 + 引流解决（CH3 / CH7）。

人均看广告次数

玩家每天主动看几次激励视频。靠广告位设计解决（CH6）。

eCPM

每千次展示报价，激励视频远高于 Banner。靠广告类型选择解决（CH6）。

留存

决定 DAU 能否持续。靠玩法与内容更新解决（CH3）。

广告变现的钱链路（IAA 模式）

1 · 广告主为「用户看完一条 30 秒视频」付费（按 eCPM 结算）
2 · 平台微信/抖音撮合并抽成——开发者通常拿约 50%，创意认证可到 70%
3 · 你提供场景，让玩家「愿意看完」这条广告（复活/道具/翻倍）
4 · 玩家免费玩，用看广告代替付费——个人开发者唯一不需要版号的路径

结论只有一句：只接广告，就先接激励视频。数据来源：2026 上半年一线服务商实测区间。

② 路线选择与推荐节奏

四条路线都有真实跑通的人。首页「入门引导」有完整对比卡，这里只给启动节奏。

📌 推荐节奏（从第一天就有反馈和现金流）

  1. 第 1 周：D 发行人计划 + A 零代码 并行启动——0 门槛、0 成本，先有正反馈。
  2. 第 2–4 周：B 微信 IAA 为主线——愿投入业余时间、想要长期资产的人重点押注。
  3. 第 2 个月起：C AI漫剧 或矩阵化——有内容感觉、能高频产出剧本的人上。

⚠️ 这样从第一天起就有现金流与反馈，不会在沉默中放弃。别一上来 All-in 单款。

③ 选题与玩法：90% 的项目死在这里

AI 把「做出来」成本打到近乎零后，胜负手全部转移到「做什么」。

经典玩法骨架 × 高共鸣题材 × 情绪价值钩子

骨架要旧

合成/消除/塔防/跑酷/答题/文字选择——被几亿用户验证过的操作，AI 也最容易做对。

题材要新

抖音爆款《赵云与阿斗》= 文字塔防 × 三国（市面独一份）；怀旧、打工人、玄学、萌系是高共鸣库。

情绪要准

《别崩人设啊》验证的三类流量题材：脑洞日常 / 社会冲突 / 轻悬疑——核心是「替用户出一口恶气/吓一跳/笑一下」。

单局时长

控制在 3–8 分钟。太短没情感连接，太长碎片化用户直接走人。

难度曲线

前 3 关教学（必过），第 4–5 关首次失败——失败点就是激励视频黄金位。《羊了个羊》式断崖难度新手慎用。

AI 量产铁律

「AI生成 ≠ 可用」。必须配校验（死局检测/难度校验），否则批量劣质关卡拉低体验、导致审核驳回——《箭头快跑呀》作者明确总结的坑。

④ AI 生产实操：三条流水线

选你资源最匹配的那条起步。

4.1 零代码路线（第 1 天即可上线）

  1. 注册平台：秒哒(miaoda) 或 腾讯代号Craft，再装 233 乐园 App 进「233工坊」。
  2. 一句话开局：「做一款 XX 题材的 XX 玩法游戏」，AI 会追问细节或生成策划案。
  3. 对话式迭代：「把怪物速度加快 20%」「加一个双倍金币按钮」——改到能连续玩 3 分钟不无聊。
  4. 一键发布到平台社区，观察真实游玩数据；好就迭代，差就换创意重开。

ChinaJoy 2026 实测：零基础上手到可玩 Demo 约 20 分钟；233 工坊熟练创作者最快 1 天完成一款并发布，平台已有 1.9 万创作者、500+ 款 AI 游戏在线。

4.2 AI 编程路线 ★主推（对标《箭头快跑呀》单人商用全链路）

环节《箭头快跑呀》选择你的等效操作
技术栈Canvas 2D + TypeScript + Vite（拒绝重型引擎）零基础更简单：Cocos Creator 或微信原生 JS
编程Cursor / Claude 辅助，单人完成VS Code + CodeBuddy（腾讯免费）；把报错原样丢回给 AI 修
美术全部 AI 生成 + 固定一张核心参考图锁画风即梦/Midjourney 出图 → 同一风格词缀生成全套 → 大图远程托管
多端业务统一、平台分层初期只做微信，跑通后复用（抖音个人上架限量，可排队）
运维自建轻后台起步用微信云开发 + 自带看板，月成本 0–30 元

✅ AI 协作心法（案例作者原话）

「人工定规范、AI 负责执行」。产品体验、代码稳定性、美术风格统一、合规风控——这四样是你的竞争力，AI 替代不了。

4.3 AI 漫剧小游戏流水线（对标《别崩人设啊》）

  1. 剧本：AI 写 3–5 分钟单元剧，开头钩子→冲突→反转→选项点。
  2. 人设锁形：定 2–3 个角色，全局锁形保证跨集不崩脸（万兴剧厂 / 即梦角色一致性）。
  3. 分镜生成：按情绪自动匹配运镜，分镜可用率约 80%。
  4. 配音字幕：AI 配音 + 口型同步 + 字幕，音色全剧锁定。
  5. 交互包装：关键节点放选项，选错重置；解锁/重置/番外挂激励广告。

关键洞察：这条路线的核心资产是内容本身就是投流素材——《别崩人设啊》单日素材投放峰值破 1 万条，成本约传统 1/10。缺点是套路化模板快速审美疲劳，必须持续产出差异化剧本。

⑤ 上架与审核：合规是 0 前面的那个 1

微信小游戏个人主体上架全流程（纯广告无需版号，软著 + 自审报告即可）。

  1. 注册 + 认证：微信公众平台注册小游戏账号，类目选「游戏」；个人主体免费认证，个体户认证 300 元/年。
  2. 办软著（最长前置，尽早启动）：中国版权保护中心或代理，800–1500 元，周期 1–2 个月。需源代码 ≥3000 行 + 说明书，名称与游戏一致。
  3. 自审自查报告 + 适龄提示 + 防沉迷：模板在微信开放平台下载，如实填写。
  4. 提审：微信开发者工具上传 → 后台提交，1–2 个工作日出结果。
  5. 开流量主：累计独立访客(UV)达标后次日开通（主流口径 500–1000 人）；也可走「游戏圈发 5 篇官方贴」加速。

驳回原因对策

高效过审心法：精准改问题、最小化迭代，不盲目重构。驳回意见指哪改哪，一次只改一处。

233乐园 / TapTap

⑥ 广告变现实操：从接入到调优

这章是手册的心脏。广告接得好不好，同款游戏月收益能差 3–5 倍。

一局游戏内的广告路径（铁律：第一个广告位永远放「死亡复活」）

  1. 主菜单 → Banner 静态展示（被动收益）
  2. 游戏中 → Banner 隐藏（保护操作体验）
  3. 关卡结束 → 插屏弹出（冷却 ≥ 2 分钟）
  4. 结算页 → 「看广告 ×2 金币」激励按钮
  5. 死亡瞬间 → 「看广告复活」（最高观看率）
  6. 每日签到 → 「看广告翻倍」（薅羊毛心理）

频次硬限：插屏单用户单日 ≤ 3 次、单次会话 ≤ 1 次；首屏严禁广告；前 3 关出现广告会导致首访用户大量流失。

代码级避坑速查（每条都是真金白银）

坑后果正确姿势
重复创建广告实例报错 1005，广告出不来全局单例，onLoad 只注册一次监听
不看 isEnded 就发奖励用户秒关也领奖励 = 被薅onClose: res.isEnded===true 才发奖
adUnitId 混用后台数据全为 0每个广告位单独创建、单独命名

奖励发放不幂等弱网双击发双份，封号风险服务端 nonce + 状态机校验

eCPM 调优五招 & 健康指标看板

① 频次分层 +25–40%

新用户低频 / 老用户中频 / 高活跃高频，别一刀切。

② Waterfall +20–50%

同一位置串联多个广告 ID 按 eCPM 降级填充，填充率从 60–70% 拉到 85%+。

③ 关键节点强出价 +10–20%

提现 / 解锁 / 获奖瞬间用户意愿最高。

④ 时段运营

晚 8–11 点、周末 eCPM 更高，拉活卡这个窗口。

⑤ 屏蔽劣质广告主

主动反馈低质广告，素材质量直接影响报价。

健康指标及格线
激励视频展示率（触发→看完）> 30%
广告填充率> 85%
Banner CTR0.5% – 2%
次日留存> 25%
人均日看广告次数（休闲类）1.5 – 3 次
算账：DAU 5000 × 人均 2 次 × eCPM 60元 ÷ 1000 × 30天 ≈ 月广告收入 1.8 万元

三个数字每提升 20%，收入就是 1.7 倍——这就是为什么要调优而不是躺平。

⑦ 引流实操：没人玩，一切归零

个人开发者没有买量预算，打「短视频自然流量 + 微信社交分发」组合拳。

一条爆款视频的结构（30 秒法则）

0–5s 钩子

冲突开场

「闺蜜说我绝对通不了这关」/ 失败名场面 / 反常识结论。5 秒完播率健康区间 45–60%。

5–15s 亮点

最爽操作

游戏最爽/最魔性的操作片段，节奏快切。

15–25s 高潮

神反转

差一点通关 / 神反转 / 彩蛋时刻，留住观众。

25–30s 转化

引导试玩

「左下角玩同款」+ 留一个评论区互动问题。

节奏：每天 1–2 条固定时段发布（中午 11:30–14:30 / 晚 17:30–21:00）；账号垂直只发一类玩法；标题带「微信小游戏+玩法词」吃搜索流量。红线：不说「点链接能赚钱」；不硬广；漫剧类优先用自己游戏内画面。

微信生态免费流量 & 冷启动阶梯

搜一搜

游戏名做好关键词，有案例零推广靠搜索流量月入 3000+ 广告分成。

好友排行榜

留存 + 自传播双引擎，务必接入；视频号发布同款，微信内跳转损耗最小。

发行人计划（路线 D）

抖音搜「游戏发行人计划」→ 实名领任务 → 选品三看（新上线/单价高/玩法简单）→ 录屏试玩剪映去重 → 双通道收益（佣金 + 看广告长尾）。

冷启动阶梯打法
0–500 UV自己 + 亲友 + 垂直社群，冲流量主门槛
500–5000 UV短视频自然流量 + 互推（同量级轻休闲互换入口）
5000+考虑小额测试投放（微信广告 50–100 元/天起步，盯回本次留）

⑧ 数据与决策：每天只看 3 个数字

AI 时代重做成本低，别恋战。数据会告诉你下一步该加内容还是换题材。

DAU今天真实打开人数。持续 <100：问题在流量端（CH7），不是游戏端。
次留<20% 直接换题材重做；25% 及格；30%+ 值得追加投入。
ARPDAU每用户每日广告收益（休闲类 0.3–1.5 元）。>1 且留存稳 = 印钞机，立刻矩阵化。

上线 7 天决策树

IF 次留 < 20% → 换题材重做（保留玩法骨架）
IF 次留 20–25% 且 ARPDAU < 0.3 → 改广告位：复活场景加激励视频
IF 次留 25%+ 且 ARPDAU > 0.3 → 每周加内容 + 加大引流
IF 连续 3 款次留 < 20% → 退回 CH3 选题，换赛道重来
IF 月广告收入连续 2 月 > 5000 → 启动企业化评估（版号/IAP/多端）

矩阵节奏：验证过的骨架，每 2–3 个月换题材/换平台再上一款，共用代码与素材库。
